# Monero logo files

Official Monero Project logo files, stored locally (never hotlinked).

- `monero-symbol.svg`: the circular symbol.
- `monero-logo-full.svg`: symbol plus "MONERO" wordmark.

Source: the Monero Project's press kit (getmonero.org). Check the press kit's current usage notes before publishing new uses.

In code, use `components/art/MoneroSymbol.tsx` rather than these files directly.

Rules:
- The symbol stands for Monero itself (coins, XMR, the network). It is never MonkStash's logo and is never merged into the monk + sprig mark.
- Recolouring is fine (official colours or a single colour). Do not distort, redraw, or change the shape.
- Never draw an improvised "M" to mean Monero.
